按積金局強制性供款表，估算僱主、僱員或自僱人士本期供款、入息上下限與實收。月入低於$7,100僱員免供、僱主仍供5%。不用註冊，不會上傳。

只供估算，並非積金局或積金易官方工具；實際以強制性公積金計劃條例、積金局公布及受託人結算為準。家庭傭工、18歲以下、65歲或以上及部分獲豁免人士不適用。

為甚麼需要這個工具

積金局網站有強制性供款表和退休策劃計算機，但沒有「這個糧期要供多少」的互動工具。本頁把月薪、周薪、半月薪、日薪與自僱按年一次計出，並標出低於下限時只有僱員免供、高於上限每方$1,500封頂。

常見問題

        

          香港強積金強制性供款怎樣計？
          
僱員及僱主一般各按僱員有關入息的5%供款，受最低及最高有關入息水平限制。月薪僱員現行最低為$7,100、最高為$30,000。低於下限，僱員無須供款，僱主仍按實際有關入息供5%；介乎兩者，雙方各供5%；高於上限，雙方各供$1,500。

        

        

          月入低於7,100元，僱主是否也不用供款？
          
要供。下限只豁免僱員那一半。僱主仍須按實際有關入息供5%。自僱人士低於下限則無須供款。

        

        

          甚麼算有關入息？
          
有關入息是僱主以金錢支付或須支付的工資、薪金、假期津貼、佣金、花紅、獎金、約滿酬金、賞錢或津貼。不包括《僱傭條例》遣散費或長期服務金、代通知金，以及發還僱員墊支的開支。非金錢利益（例如免費膳食、旅遊套餐）一般也不計。

        

        

          新僱員免供款期有多久？
          
僱員無須為受僱首30日供款，並可能伸延至其後首個不完整糧期。免供款期不適用於僱主。首次把僱主及僱員供款交到積金易，一般是僱員受僱滿60日所在月份完結後的下一個供款日（通常每月10日）或之前。

        

        

          自僱人士怎樣供？
          
自僱人士按有關入息的5%供款，可選按月或按年。現行最低／最高為每月$7,100（每年$85,200）及每月$30,000（每年$360,000）。低於下限無須供款；高於上限每月$1,500或每年$18,000。有關入息可用最近期評稅通知書的應評稅利潤等積金局認可方法確定。

        

        

          這是不是積金局或積金易官方計算機？
          
不是。積金局官方是供款表和退休策劃計算機，沒有本期供款互動工具。本頁只按公布的上下限做估算，不能代替付款結算書或受託人紀錄。建造業／飲食業行業計劃的臨時僱員供款方法不同，本頁不涵蓋。

        

        

          資料會上傳嗎？
          
不會。金額只在瀏覽器內計算，草稿可寫入本機 localStorage。沒有帳戶、沒有伺服器存檔。
