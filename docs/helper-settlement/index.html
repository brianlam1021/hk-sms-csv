常見問題

這和每月外傭工資收據有何分別？

每月糧單記錄該期工資與假期。本頁是合約期滿或提前終止時的一頁結算單，用來列出未付工資、未放年假、代通知金與回程旅費。兩者互補，不是同一份文件。

會計算遣散費或長期服務金嗎？

不會。本頁不計算遣散費、長期服務金或強積金對沖。如可能適用，請用勞工處法定僱傭權益參考計算機核對。

膳食津貼和回程膳食交通津貼幾多？

不提供免費膳食時，勞工處外傭專頁現時列明每月不少於 HK$1,236。回程期間膳食及交通津貼在標準合約常見為每日 HK$100。本頁欄位可改，請以公布及合約為準。

回程機票要怎樣處理？

合約期滿或終止時僱主須提供返回原居地的旅費。勞工處指南一般建議提供直航機票。本頁可註明已提供機票，或填寫現金代替金額。

資料會上傳嗎？

不會。全部只在你的瀏覽器運算，並可選擇寫入本機 localStorage。沒有帳戶、沒有伺服器存檔。
