僅供參考，並非法律／稅務意見；亦非稅務局官方工具或繳稅單。實際以印花稅條例、e-Stamping 及印花稅署評定為準。

為甚麼需要這個工具

站內已有「租約印花稅」與「物業稅」，但物業買賣從價印花稅是另一套稅表。稅務局有官方計算機，本頁把住宅第一／第二標準、非住宅第三標準、邊際寬減，以及已取消的 BSD／SSD／NRSD 一次列明，方便睇樓或簽臨時買賣合約前粗略對照。

常見問題

香港物業買賣印花稅怎樣計？

從價印花稅（AVD）按代價或物業市值（以較高者為準）計算。2026年2月26日起，住宅適用第一標準第1部／第二標準（稅率相同，逾約1.0957億元可達6.5%）；非住宅適用第三標準（最高4.25%）。印花稅含不足1元之數向上取整至1元。

還要交買家印花稅、額外印花稅或新住宅印花稅嗎？

自2024年2月28日起，住宅物業交易已取消買家印花稅（BSD）、額外印花稅（SSD）及新住宅印花稅（NRSD／舊稱第一標準第1部劃一稅率）。本頁對該日起文書顯示此三項為零。稅務局／立法會文件沒有「AVSD」此一獨立稅項；現行物業買賣主要是從價印花稅（AVD）。

第一標準與第二標準有分別嗎？

自2024年2月28日起，第一標準第1部稅率已改為與第二標準相同。香港永久性居民購入唯一住宅仍可按第二標準加蓋，但現行數字與第一標準第1部一樣。2026年2月26日起住宅再加設逾1億元的6.5%稅階。

這頁會估算租約印花稅或物業稅嗎？

不會。租約印花稅見「租約印花稅」工具；出租收入的物業稅見「物業稅」工具。本頁只估算物業買賣／轉讓的從價印花稅。

資料會上傳嗎？

不會。估算只在瀏覽器內計算。代價與市值不會寫入 localStorage。沒有帳戶、沒有伺服器存檔。
