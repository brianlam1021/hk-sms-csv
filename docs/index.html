短訊記帳CSV

支援滙豐、恒生、中銀、渣打的卡簽賬短訊，英文或繁體中文皆可。解析日期、金額、商戶、銀行與卡尾，然後下載可供 Excel 開啟的 UTF-8 BOM CSV。

本頁只把你貼上的文字格式化。不是銀行夥伴、不是戶口結餘、也不是詐騙偵測。

使用方法

  1. 從手機短訊複製信用卡簽賬通知；若只想試用，按「載入示範短訊」。
  2. 貼到下方文字框。解析只在這個瀏覽器進行，不會上傳。
  3. 核對摘要、預覽，以及未能辨識的行，再下載 CSV。

        常見問題

        短訊會上傳嗎？要註冊嗎？

        不用註冊，也不會上傳。這個靜態頁只在瀏覽器內處理你貼上的文字，沒有後端、沒有分析程式。

        會否把資料寫進電腦？

        不會寫入 localStorage，也不設雲端存檔。離開頁面或按清空後，內容即消失。只有你主動下載的 CSV 會留在你選擇的位置。

        支援哪些銀行與語言？

        目前對準香港滙豐、恒生、中銀、渣打的信用卡簽賬短訊，英文或繁體中文。銀行格式不時改動，未能對上的行會單獨列出。

        未能辨識的行會怎樣？

        會留在頁面上供你查看，但不計入總額、筆數、按銀行／按商戶，也不會進入下載的 CSV。

        這是不是銀行官方工具、結餘查詢或防詐系統？

        不是。本頁不是任何銀行的夥伴或官方服務，不會顯示戶口結餘，也不做詐騙偵測。它只把已貼上的文字格式化成表格與 CSV。

        示範短訊是否真實客戶資料？

        不是。載入示範短訊只使用虛構卡尾、虛構金額與常見商戶名稱，用來示範解析。請不要把真實他人短訊公開分享。

        CSV 用什麼編碼？

        UTF-8 並加上 BOM，方便 Excel 直接開啟中文欄位。欄位為日期、金額、貨幣、商戶、銀行、卡尾。
