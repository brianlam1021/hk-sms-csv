按運輸署2024年7月14日起收費表，估算市區、新界或大嶼山跳錶、等候、行李、電召與隧道附加費。不用註冊，不會上傳。

只供估算，並非運輸署官方工具或跳錶；實際以憲報收費表、車廂收費表及的士跳錶為準。本頁不規劃路線、不讀GPS。

為甚麼需要這個工具

運輸署網站有市區／新界／大嶼山收費表和換算表PDF，但沒有把路程、等候、行李與過海回程一次加起來的互動頁。官方表在手機上要橫看，隧道附加費又分過海回程與其他隧道。本頁把憲報數字在瀏覽器內加總，方便對照跳錶或預先帶現金。

常見問題

        

          香港市區的士跳錶怎樣計？
          
由2024年7月14日起，市區的士首2公里（或其部分）$29。其後每200米或每分鐘等候（或其部分）先加$2.1，直至應收款額達$102.5；之後每格$1.4。行李每件$6、動物／鳥類每隻$5、電召每程$5。過海隧道一般是隧道費$25加回程$25。

        

        

          過海的士何時不用付回程費？
          
運輸署列明：在過海的士站上車，或最終目的地並非海港另一方，乘客毋須繳付$25回程費，但仍須付該程$25隧道費。

        

        

          新界同大嶼山有何分別？
          
新界的士旗落$25.5，其後每格$1.9直至$82.5，之後$1.4。大嶼山旗落$24，其後$1.9直至$195，之後$1.6。行李、動物、電召三類附加費相同。新界表另列大欖$28、城門$8；大嶼山表沒有隧道附加費。

        

        

          這是不是官方跳錶或GPS車資？
          
不是。運輸署只公布靜態收費表與換算表，沒有互動估算器。本頁按你填的路程與等候在瀏覽器內加總，不是稅表跳錶，也不用地圖或收費API。實際以車廂收費表及跳錶為準。

        

        

          資料會上傳嗎？
          
不會。路程與附加費只在瀏覽器內計算，草稿可寫入本機 localStorage。沒有帳戶、沒有伺服器存檔。
