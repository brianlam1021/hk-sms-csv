# 四字紙皮

輸入最多四個字（心情或狀態，不是真實地址），瀏覽器即場畫一塊虛構港式紙皮石門牌，存成 PNG 轉發。

此門牌屬虛構，不可當真實地址或門牌使用。

本頁是單一靜態玩具：無後端、無帳戶、無廣告、無分析、無付款。

## 本機預覽

需要 Node.js。

```bash
npm install
npm run dev
```

瀏覽器打開終端顯示的本機網址。預設埠是 `43173`。

打一至四個字，睇到一塊牌，再撳「存圖」。

## 公開（GitHub Pages）

1. 把此儲存庫設為公開。
2. `npm run build`，產出在 `dist/`。
3. 用 GitHub Pages 發佈 `dist/`，或把 `dist` 內容推到 Pages 所用的分支。

站點保持細小，遠低於 Pages 的 1 GB 上限。不要把此頁做成商店或收款頁。
