# 紅白藍金句袋

打一句短中文或粵語，頁面畫成一個虛構港式紅白藍行李膠袋，存成 PNG 即可轉發。

此袋是迷因圖像，不是寄運標籤、報關單或身分證明。沒有條碼、沒有追蹤編號、沒有公章。

這不是四字紙皮。袋面是原創簡筆編織膠袋，與任何品牌、工作室或官方機構無關。

## 本機運行

```bash
npm install
npm run dev
```

瀏覽器打開 http://127.0.0.1:43173/

只係一個靜態頁：`index.html`、`css/styles.css`、`js/bag.js`、`js/main.js`。無後端、無帳戶、無分析、無電郵表單、無商店。

## GitHub Pages

把這個公開 repo 開成預設 github.io 即可，根目錄直接派靜態檔。不用自訂網域，也不用 build。

## 用法

1. 輸入最多 12 個字。
2. 預覽一個紅白藍膠袋。
3. 按「存成 PNG」下載圖片再轉發。
